# Fluoroscopy to Cine QR code

Both files encode this exact URL directly:

https://highsg19101.github.io/fluoro-to-cine-project/

- `fluoro-to-cine-qr.png`: high-resolution black-and-white image for sharing.
- `fluoro-to-cine-qr.svg`: vector version for printing at any size.

This is a static QR code with no expiration, tracking service, URL shortener, or subscription. Updating the website's content does not require changing the QR code while its URL stays the same. Continued access depends on keeping the GitHub account, repository name, and Pages publishing available at this address.

Generated with Python `qrcode` 8.2, error correction Q, and a four-module white quiet zone. Keep the surrounding white border when printing or placing the code in a document.
